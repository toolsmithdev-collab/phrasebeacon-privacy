隱私權政策 / Privacy Policy

中文（繁體）

簡要說明：PhraseBeacon 會在使用者明確同意後，於裝置本機處理網頁可見文字與使用者提供的設定，以提供關鍵字標記、命中統計、位置導覽及備份還原。資料不會傳送給開發者或第三方。

處理的資料與用途

  • 網站內容：即時讀取目前頁面及可存取頁框的可見文字，以尋找並標記關鍵字。文字不會持久保存或傳送。
  • 使用者設定：清單名稱、關鍵字、顏色、比對選項、順序、開關、語言及同意版本儲存在 chrome.storage.local。
  • 命中統計：只暫存在瀏覽器記憶體中，用於徽章及位置跳轉。
  • 檔案：僅在使用者主動操作時於本機讀取 CSV/JSON 或建立 JSON 備份，絕不上傳。

PhraseBeacon 排除輸入欄位、密碼欄位、可編輯區域、指令碼及樣式。一般可見文字仍可能包含個人或敏感資訊，但只在本機即時比對。

分享、傳輸與保留

PhraseBeacon 不使用伺服器、分析、遙測、廣告、聯盟行銷、跨網站追蹤或使用者輪廓分析；不出售或分享資料。網站文字不保留。設定保留到使用者刪除、清除擴充功能資料或解除安裝。

權限與使用者選擇

storage 用於本機設定；所有網站的內容腳本存取用於核心跨網站醒目標記。首次同意前不會掃描或標記。使用者可用總開關暫停，或在 Chrome 設定限制網站存取。

Limited Use

PhraseBeacon 對資料的存取與使用僅限於提供及改善已揭露的單一用途，並遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。資料不會用於廣告、信用評估、資料轉售或未揭露用途。

變更與聯絡

重大資料處理變更會在開始前透過擴充功能顯著揭露，並在需要時重新取得同意。如有問題，請使用 Chrome Web Store 商店頁面列出的開發者電子郵件或支援連結。

English

Summary: After explicit consent, PhraseBeacon processes visible webpage text and user-provided settings locally to provide highlighting, match counts, navigation, and backup/restore. No user data is transmitted to the developer or third parties.

Data processed and purposes

  • Website content: Visible text in the current page and accessible frames is processed in real time to find and highlight keywords. It is neither retained nor transmitted.
  • User settings: List names, keywords, colors, match options, order, enabled state, language, and consent version are stored in chrome.storage.local.
  • Match statistics: Temporary in-memory counts power the badge and match navigation.
  • Files: CSV/JSON files are read and JSON backups are created locally only after a user action. Files are never uploaded.

PhraseBeacon excludes form inputs, password fields, editable regions, scripts, and styles. Ordinary visible text may still contain personal or sensitive information, but matching remains local.

Sharing, transmission, and retention

PhraseBeacon uses no servers, analytics, telemetry, ads, affiliate marketing, cross-site tracking, or profiling. It does not sell or share data. Page text is not retained. Settings remain until deleted, extension data is cleared, or the extension is uninstalled.

Permissions and user choice

storage stores local settings. Content-script access on all websites provides the core cross-site highlighting feature. No page is scanned or highlighted before consent. Users can pause highlighting or restrict site access in Chrome.

Limited Use

PhraseBeacon limits data access and use to providing and improving its disclosed single purpose and complies with the Chrome Web Store User Data Policy, including Limited Use requirements. Data is never used for advertising, credit assessment, resale, or an undisclosed purpose.

Changes and contact

Material data-practice changes will be prominently disclosed in the extension before they begin, with renewed consent where required. For questions, use the developer email or support link on the Chrome Web Store listing.
